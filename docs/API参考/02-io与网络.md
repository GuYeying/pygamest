## pygame.io（跨平台读写 + 分发装载链）

```python
await pygame.io.fetch(path) -> bytes        # 底层通用口（异步；三平台同语义）
pygame.io.io_take(path) -> bytes            # 哈希链取走（桥内部用——游戏侧走 fetch）
pygame.io.io_ready(path) -> bool            # 完成表就绪判定（任务泵用）
pygame.io.io_pending_append(path)           # 任务挂起压队（桥内部用）
pygame.io.payload_list() -> list[str]       # 分发清单（逻辑路径）
pygame.io.read_text(path) / read(path)      # 同步文本/字节（native）
pygame.io.write_text(path, text) / write(path, bytes)
pygame.io.exists(path) -> bool
```

- **fetch 链**：`fetch` 读 `.py` 自动注册 import（分发形态模块装载）；
  加密分发形态自动解密（哈希定位：`modules/<hash>.sfx`、`assets/<hash>.sfx`）
- 无路径场景：`fetch → *_from_bytes`（image/mixer/font 三线统一）
- Web：fetch no-store（更新即取新）；native：基准目录 fs（基准 =
  exe 同级，镜像源结构）
- `[差异]` **异步是设计定约**：跨平台 IO 兼容优先（Web 无同步文件系统）

## pygame.net（TCP 消息连接 / UDP 轮询）`[待验收]`

```python
conn = pygame.net.TcpConn.connect("host:port")   # Web = WebSocket（裸地址自动加 ws://）
conn.state() -> ConnState                        # Connecting / Connected / Closed
conn.send(frame: bytes)                          # 4 字节大端长度前缀分帧，单帧上限 16MB
conn.try_recv() -> bytes | None                  # 非阻塞轮询
conn.close()
sock = pygame.net.UdpSock.bind("0.0.0.0:7777")   # Web = UnsupportedPlatform
sock.send_to(data, peer) / try_recv_from() / set_broadcast(True)
```

- 轮询式语义（帧内 send/try_recv，主线程永不阻塞）；原生每连接后台线程
- Connecting 期间 send 自动入队（连接成功后冲刷，缓冲 512 帧上限）
