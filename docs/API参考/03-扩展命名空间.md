## pygame_gui（egui 对接）

```python
import pygame_gui as egui

class HUD(egui.UiBase):
    def draw(self, ui):                      # OOP 门面：panel 强制继承 UiBase
        ui.heading("...")
        ui.label("...")
        if ui.button("点我"):
            ...
        self.checked = ui.checkbox("复选框", self.checked)
        self.gravity = ui.slider_f32("重力", self.gravity, 0.0, 20.0)

panel = HUD(game)
# 渲染会话内叠加（恒在游戏内容之上）：
with screen.render() as r:
    egui.event(e)                            # 事件逐条显式喂（event.get() 循环内）
    r.draw_ui(panel)                         # 嵌套布局 with 语法：with ui.horizontal():
```

- 中文渲染验收 ✅（egui-starfish-we 适配层，vendored egui-winit 0.37 fork）
- `egui.wants_pointer() -> bool`：指针是否悬在可交互控件上
- 事件不喂则无输入（数据流层完全可见）

## pygame_physics（Rapier 原生词汇）

```python
import pygame_physics as rp

world = rp.PhysicsWorld(gravity=(0.0, -9.81))
body = rp.RigidBodyBuilder("fixed", translation=(0.0, -2.0))   # fixed/dynamic
collider = rp.ColliderBuilder.cuboid(hx, hy)                    # 原生 Rapier 词汇
# 帧内步进 + 会话排程调试线：
world.step()
with screen.render() as r:
    r.draw_debug(renderer, sink)
```

- 2D / 3D 双维度（`physics2d` / `physics3d` feature，`dim2::` / `dim3::`
  命名空间并存）；不 pygame 化（原生词汇直通）

## pygame.tasks（微调度器——asyncio 游戏子集）

```python
task = pygame.tasks.spawn(coro)              # 协作式任务（帧泵驱动）
await pygame.tasks.gather(t1, t2)
await pygame.tasks.sleep_frames(n)           # 帧粒度休眠
pygame.tasks.frame() -> int                  # 当前帧号
```

- 任务内 io 挂起语义与主协程一致（就绪前不 send——提前恢复病态防护）
