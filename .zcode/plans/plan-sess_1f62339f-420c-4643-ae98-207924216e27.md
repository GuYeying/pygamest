# 渲染域定约 v3：Auto 相机退役 + 域分层显式化 + 历史兼容清零

## Context

域冲突实锤（fluid2d_test 的 HUD 像素值 ±400,±300 画在 14×8 米制相机 None 段——能显示纯属数值巧合）+ Auto 隐式相机（随 init(dim=3) 隐式变透视）+ 双 Camera 类型并存 + CameraKind 死枚举。用户定约：
1. **pygame 像素图元 API（draw/blit/gfxdraw 无相机口/字体）恒像素域**——与相机彻底解耦
2. **引擎 MVP 目标域全面 NDC**：无显式相机 = NDC 恒等直通；Auto 相机（refresh_camera else 分支、构造默认 ortho、wish 喂相机）死绝
3. **set_camera 一次设置缓存**：相机对象跨会话/resize/换画布不动；fit 由现行两段式机制独立现算（用户原话："resize 触发 fit 矩阵重计算，py 走 set_camera 填入相机矩阵，消费时乘 fit"）——零新机制
4. **绝对架构级干净**：历史兼容层尽可能清零；仅引擎边界无法直改的（egui mid 面合成结构、egui-starfish-we 桥）保留为文档定约化的兼容层

## 定约后的域分层

| API 面 | 域 | 实现 |
|---|---|---|
| pygame 像素图元（draw.rect/blit/gfxdraw 无相机口/字体） | **恒像素域** | pack None 段 = `present_fit × 像素正交`（固定单点，不读相机） |
| gfxdraw.set_camera(t, cam) | 会话级段 override | 保留——但**类型统一为 GameCamera**（见下） |
| raw 段/裸管线（自写 WGSL） | **NDC 直通** | 无相机 = NDC 恒等；`write_camera_mvp(buf)` 单参 = present_fit |
| 显式 Screen 相机 | world→画布基底 | 只消费于 write_camera_mvp 单参 / rapier debug follow——一次设置缓存 |
| t.fill / Surface / pack_mrt / blit_fullscreen | 恒像素 | 数学不变（logical 正交），语义重述 |
| 事件映射 | 恒 logical 像素中心原点 | 现状不动（与相机零耦合） |

**数学恒等保证**：现状 Auto = `fit_ndc × ortho(±lw/2)`，分解 = `present_fit × ortho(logical,logical).mvp()`——恒像素段即此分解形态，不设相机的 54 案例逐位不变。

## 改动清单

### starfish/crates/starfish-pygame

**target.rs（核心）**：
- `camera: RefCell<GameCamera>` → `RefCell<Option<GameCamera>>`；构造初始 None
- `camera_explicit: Cell<bool>` 删除；`refresh_camera()` 整体删除；`set_logical_size` 同尺寸守卫段落删除（旗标消亡）；resize 只留 surface 侧
- `pack()` None 段：新增私有单点 `pixel_ortho_mvp()`（= `GameCamera::ortho(logical, logical).mvp()`）——**同时作为 egui compose / physics Surface 口的统一像素正交基底**（见下）
- `present_mvp()` = `camera.map(mvp).unwrap_or(ndc().mvp())`
- 陈旧注释清（CameraState 残留 :275/:284、Auto 话术、t.fill 段重述）

**camera.rs（GameCamera）**：新增 `ndc()` 构造（identity MVP 具象）；文件头定约更新（显式 = 唯一域切换口、无相机 = NDC 默认、缓存跨生命周期）

**render/camera.rs + render/mod.rs（双类型统一——本次干净化主刀）**：
- **`render::camera::Camera` 整体退役**——唯一 Camera 类型 = GameCamera（crate::camera）
- `CameraKind`（Auto2d/Auto3d）+ `resolve_mvp` 死枚举删除
- `RenderPass::set_camera`（target.rs:236）/ gfxdraw 会话快照 / MRT 会话口全部改收 GameCamera——**数学兼容证明**：gfxdraw 会话相机构造 logical==physical → fit_ndc 恒等 → mvp() = 纯投影，Some 段 `fit × cam.mvp()` 逐位不变（center_origin_demo/gfx3d_demo/leak_i_gfx3d 零迁移）
- `camera_mvp()/camera_mvp_for`（mod.rs:236-243）**退役**——四消费点（pygame_gui runtime.rs:495/538、physics runtime_2d.rs:1039、runtime_3d.rs:1151）统一改走 `pixel_ortho_mvp()`/同数学（Surface 版传目标尺寸）；render.rs:505 的 py 暴露 `camera_mvp` 同步退役或改指向恒像素单点

### pygamest（pygame-rs/src/rpy）

- **mod.rs `screen.set_camera`**：Option 化适配（None 不回写）；注释更新（显式唯一 + 缓存）
- **render.rs `write_camera_mvp`**：单参逻辑零改（present_mvp None → NDC 恒等）；注释更新；`camera_mvp` py 口随 starfish 退役处理
- **gfxdraw.rs**：set_camera 收 PyGameCamera（类型统一）；会话相机构造口（py 层 camera_perspective/ortho 等 render 侧构造）统一迁移到 game_camera_* 系列——**py API 面收敛为单一相机类型**
- **pygame_gui runtime.rs compose 链**：`camera_mvp_for(logical)` → `pixel_ortho_mvp()`（同一恒像素单点）；egui mid 面合成结构**保留**（用户点名的必要兼容层——egui_wgpu 不吃引擎矩阵，文档定约化）
- **physics runtime_2d/3d**：follow 分支读 present_mvp/present_fit（实现零改）；Surface 版 draw_debug 改走统一像素正交
