# 1.0 路线图

> 1.0 的含义 = **API 稳定承诺**（升级不再随意 breaking），不是"功能做完"。
> 本文件是推进清单：每完成一项打勾，全绿即可宣布 1.0-rc。

## 一、测试覆盖矩阵（现状 → 目标）

### 已有锚点 ✅

| 面 | 锚点 | 位置 |
|---|---|---|
| 引擎模块验收 | `pygame_test_*` 家族（display/event/io/color/time/surface/mask/key/mouse/math…，桌面+Android 双形态） | pygamest 仓 examples/demos |
| 绑定面专项 | draw_test / font_test / egui_test / rapier_test / letterbox_probe / parity_test / transparent_test / surface_size_probe | pygamest-dev/examples |
| 契约锚点 | sig_probe（130+ 项断言）/ binding_probe / rp_hello | pygamest/examples |

### 缺口（1.0 前须补）⚠️

| 模块 | 现状 | 目标 |
|---|---|---|
| `net` | 类型+骨架（TCP 分帧有单测，绑定面无脚本验收） | 回环脚本验收（TCP echo / UDP pair） |
| `dialog` | 绑定存在，无脚本验收 | 桌面打开/保存各一例 |
| `video` | 硬解抽象（无硬解报错），无验收 | Windows MF 一例 + Web 例外断言 |
| `gamepad` `touch` | 绑定存在，真机验收缺失 | 真机各一例（手柄按键 / 双指） |
| `sndarray` `sprite` | 绑定存在，无验收 | 与 numpy 互操作一例 / Group 池化一例 |
| `mixer` 效果器链 | Effect 绑定存在，无脚本验收 | 效果器链一例 |
| 加密分发链 | runtime 侧 verify_export 全绿 ✅ | Web 形态端到端一例入 CI |

## 三、稳定性准则

- 进入 1.0-rc 前：Python 面旗标/函数签名冻结，只增不破
- 破坏性变更必须在 CLAUDE.md 批次记录 + docs 差异表双处登记
- 语义偏差（如异步资源链、render 会话、单窗口契约）视为**设计定约**
  而非偏差累计——1.0 文档须正面陈述而非逐条打补丁

## 四、平台验收（1.0 发布门槛）

- Windows 桌面：核心循环全绿 ✅（持续保持）
- Web：核心循环全绿 ✅（音频手势解锁边界文档化）
- Android：真机（鸿蒙 NEXT + 卓易通）核心循环全绿（进行中）
- 全屏/窗口形态：已实测定证（2026-11-03，Win32 rect+style 双取证）✅

## 五、非目标（1.0 明确不含）

- 多窗口（feature 白名单外）
- pip 安装包 / wheel 分发（Phase7）
- Python 3.12+ 语法特性对齐（RP 解释器能力边界）
