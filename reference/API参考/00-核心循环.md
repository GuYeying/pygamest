# API 参考：核心循环（display / event / key / mouse / time / 帧桥）

> 事实源：`src/rpy/pygame/{display,event,key,mouse,time,mod}.rs`。
> `[差异]` = 与真 pygame 的语义差异；未标注 = 尽量 1:1。

## pygame.display

```python
pygame.display.set_mode(size, flags=0) -> Screen   # [差异] 见下
pygame.display.flip()
pygame.display.set_caption(title)
pygame.display.set_opacity(v: float)               # 0.0~1.0，Windows 合成器支持时
pygame.display.get_init() -> bool
```

### set_mode

- `size` = **display 逻辑尺寸**（ADR-8：此后窗口 resize 不改 display 尺寸；
  Android 窗口化例外——逻辑归脚本、物理恒原生窗口，呈现等比映射）
- `flags`：int 位掩码或 `[位, ...]` 序列（pygame 两形态都收）
- 常量**顶层与 pygame.display 同名同值**：`RESIZABLE FULLSCREEN NOFRAME
  HIDDEN ALWAYS_ON_TOP TRANSPARENT VULKAN DIRECTX METAL OPENGLES OPENGL`
- **默认不可 resize**：`RESIZABLE` 需显式传入；`FULLSCREEN` = 无边框铺满
  所在显示器（真全屏形态）
- `[差异]` 本调用**建真身窗口**（进程一次；宿主壳预建 800×600，脚本
  set_mode 即时生效尺寸+旗标）；重复调用 = 契约违例 panic
- 旗标位见下方"旗标应用顺序"注记；创建期专属：`TRANSPARENT`（Windows
  DX12+DWM 直通）、后端声明（VULKAN/DIRECTX/METAL/OPENGLES/OPENGL，
  首次 set_mode 定终身，不可用隐式退化回全后端）

### 渲染会话（与 flip 配合）

```python
with screen.render() as r:
    r.fill(color)
    r.blit(surface, dest)              # dest = (x, y) 或 4 元裁剪形式
pygame.display.flip()                  # 帧提交（batch flush + present）
```

`Surface.render()` 同款会话（离屏批量绘制）；`flip` 时 egui/物理调试线
自动叠加在游戏内容之上（会话排程形态）。

## pygame.event

```python
pygame.event.get() -> list[Event]      # 取走全部（非阻塞轮询）
pygame.event.poll() -> Event | None
pygame.event.clear()
```

`Event.type` / `Event.key` 等：`pygame.event.QUIT` `KEYDOWN`…
（位值与类型沿用 pygame 命名）。事件由 `Window::poll_event()` 主线程
泵出（pull 模型，无回调）。

## pygame.key / pygame.mouse

- `pygame.key.get_pressed()` -> 位序列（`pygame.key.K_*` 常量，KMOD_* 修饰位）
- `pygame.mouse.get_pos()` / `get_pressed()` / `set_visible()`
- 坐标 = display 逻辑坐标（物理→逻辑映射已内置，HiDPI 安全）

## pygame.time

```python
pygame.time.get_ticks() -> int         # ms，单调
pygame.time.delay(ms)                  # 阻塞（主线程慎用——网络/IO 独立于主线程）
pygame.time.Clock() -> Clock
Clock.tick(framerate=0) -> ms          # 帧率控制；[差异] 非 busy-wait
```

## 帧桥（跨平台统一挂起点）

```python
await pygame.next_frame()              # 每帧帧尾必调
```

- 入口严格 `async def main():`——生成器 `yield` 形态已退役
- Web = rAF 桥（嵌入式 webview 无 rAF 时自动 setTimeout 兜底，
  保证帧推进）；桌面 = 事件泵 + 帧拍

## 顶层旗标常量

`pygame.RESIZABLE / FULLSCREEN / NOFRAME / HIDDEN / ALWAYS_ON_TOP /
TRANSPARENT / VULKAN / DIRECTX / METAL / OPENGLES` —— 与
`pygame.display.*` 同名同值（此前只挂 display 层，2026-11-03 补顶层）。
