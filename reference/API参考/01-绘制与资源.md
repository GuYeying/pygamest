# API 参考：绘制与资源（draw / Surface / gfxdraw / image / font / mixer）

> 事实源：`src/rpy/pygame/{mod,font,image,mixer,gfxdraw}.rs` 与
> starfish-pygame `draw.rs`。`[差异]` = 与真 pygame 语义差异。

## Surface（GPU 出生面）

```python
surf = pygame.Surface((w, h))                  # GPU 出生面；[差异] depth_buffer
surf = pygame.Surface((w, h), depth_buffer=True)  # 深度缓冲（真 pygame bpp 语义已禁）
surf.get_size() -> (w, h)
surf.fill(color)
surf.blit(source, dest)
surf.blit_transform(source, dest, transform)   # [新增] 旋转缩放贴图
surf.blit_area(source, dest_rect, src_rect)    # [差异] 裁剪贴图（GPU 采样）
surf.set_alpha(value)
surf.render() -> Session                       # 离屏绘制会话（同 screen.render()）
```

## 渲染会话（Screen / Surface 通用；排程式，退出时批量落 GPU）

```python
with surface.render() as r:
    r.fill(color)
    r.rect(color, rect, width=0)               # width=0 填充，>0 描边
    r.circle(color, center, radius, width=0)
    r.line(color, start, end, width)
    r.polygon(color, points, width=0)          # 凹多边形支持（耳切三角化）
    r.ellipse(color, rect, width=0)
    r.arc(color, rect, start_angle, end_angle, width=1)
    r.blit(surface, dest)
    r.blit_transform(surface, dest, transform)
    r.blit_area(surface, dest_rect, src_rect)
    r.draw_ui(panel)                           # [pygame_gui] egui 面板叠加
    r.draw_debug(renderer, sink)               # [pygame_physics] 调试线
```

- 颜色形态：`(r,g,b)` / `(r,g,b,a)` / `(r,g,b,a=255)` kwargs / 命名色（内嵌
  色表：`Color("name")`）
- 半透明叠加：alpha 混合管线（Alpha / Additive / Multiply / Custom）

## pygame.gfxdraw（兼容层）

`pixel / line / circle / ellipse / arc / polygon / …` —— 与真 pygame
gfxdraw 参数形态 1:1（坐标 int 化），实现走 GPU 会话。

## pygame.image

```python
pygame.image.get_extended() -> bool
pygame.image.load(path) -> Surface          # [差异] async 语义见下
pygame.image.load_from_bytes(bytes) -> Surface
pygame.image.save(surface, path)            # 桌面（Web 报 NotImplementedError）
```

- `[差异]` **load 为异步语义**：分发形态（pygamest-runtime）下走
  fetch+解密链——游戏侧以 `await` 承载（见 hello_word）；无路径场景用
  `pygame.io.fetch` + `load_from_bytes`
- 缺资源不崩溃 = 占位图顶上（品红棋盘格）+ Error 日志；严格模式
  `STARFISH_STRICT_ASSETS` 恢复真异常
- 格式：PNG / JPEG / BMP / GIF / WebP（按内容探测）

## pygame.font

```python
pygame.font.Font(path_or_alias, size) -> Font
pygame.font.Font(None, size)                # 内置默认字体
Font.render(text, antialias=False, color=(255,255,255)) -> Surface
Font.size(text) -> (w, h)
```

- CJK 预载链：`pygame.font.Font("cjk", size)`（别名，dev 解释器预载；
  分发形态走 io.fetch 字体文件 + load_from_bytes 同义面）
- 自研扫描线光栅化（非零环绕 + 4×4 超采样），GPU 出生面

## pygame.mixer

```python
pygame.mixer.init(channels=None)            # 缺省 8 通道；Web 首次手势解锁后生效
pygame.mixer.get_init() / quit() / get_busy()
pygame.mixer.set_master_volume(v)
pygame.mixer.set_reserved(n)                # 保留通道
pygame.mixer.num_channels() -> int
pygame.mixer.output_sample_rate() -> int
pygame.mixer.beep() -> Sound                # [新增] 内嵌提示音

pygame.mixer.Sound(bytes) -> Sound          # [差异] 仅 bytes 构造（路径构造退役）
Sound.play(...) / stop() / set_volume(v) / get_length() -> f32

ch = pygame.mixer.Channel(0)
ch.play(sound, loops) / stop() / pause() / resume() / set_volume(v)
ch.add_effect(effect)                       # [差异] 效果器链（AudioEffect trait）
fx = pygame.mixer.Effect("gain")            # [新增] 命名效果器（DSP 自定义）
fx.set("gain", 0.5)
```

- 格式：OGG / MP3 / FLAC / WAV 按内容探测（symphonia）
- Web：首次手势解锁（`pygame.mixer.needs_gesture()`）；流式解码由引擎
  mixer pump 驱动
