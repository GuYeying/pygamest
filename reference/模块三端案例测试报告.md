## 三、内存泄漏检查（Windows，复合探针 leak_io_net_video.py）

探针构成：io 写读循环 ×200 + net TCP 连断 ×20 + video 全开重开 ×N
（每支 12 帧 + frame() 采样）。RSS 采样（log 标记同步采样）：

| video 重开次数 | RSS 增量 | 边际成本 |
|---|---|---|
| 20 | +200 MB | 10.0 MB/次 |
| 60 | +293 MB | 4.9 MB/次 |
| 200 | +565 MB | 2.8 MB/次 |

**判定**：边际成本递减（10 → 4.9 → 2.8）——主体为解码器/堆池化稳态
保留，无线性泄漏证据。60→200 段残留 ~1.9 MB/次 的弱增长**不排除
MF/COM 层小幅残留**——后续按 `reference/如何调试寻找内存泄漏.md`
流程做会话级深查（非阻塞项）。io/net/dialog 未见增长信号。

## 四、运行手册

```bash
# Windows（CWD=web/ 使 assets/ 可达）
D:/Projects/Rust/pygame-rs-dev/target/release/python.exe ../examples/io_test.py
# net 需先起回声服务（两端口）：
python net_echo_server.py      # raw TCP 9001（桌面/Android 经 10.0.2.2）
python net_echo_ws_server.py   # WebSocket 9002（Web 端）
# video 需测试片（CC-BY，本地暂存不入库）：
curl -o web/assets/video/bbb_10s.mp4 \
  "https://test-videos.co.uk/vids/bigbuckbunny/mp4/h264/360/Big_Buck_Bunny_360_10s_1MB.mp4"
# 同款拷 examples/assets/video/（桌面模块根暂存）

# Web
python web/build.py            # host 编译（nightly：RUSTUP_TOOLCHAIN=nightly）
cd web && python.exe serve . 8123
# 浏览器 http://127.0.0.1:8123/?script=io_test.py（net/video/dialog 同）

# Android
adb reverse tcp:9001 tcp:9001 && adb reverse tcp:9002 tcp:9002
adb install -r target/apk/pygamestdev_demo.apk
adb shell am start -n pygame.rsdev/pygamestdev.ScriptActivity -e script io_test.py
```

## 五、站桩语义备忘（v1 设计行为，非缺陷）

- **dialog**：Web/Android 同步口显式 ValueError（异步 job API 后续批次）；
  桌面模态对话框需人工点选（案例只跑面检查）。
- **io**：Web 同步口显式 ValueError（宿主预载/异步资源装载承载）；
  异步通道（io_pending_append/io_ready/io_take）三端可用。
- **video**：Web 端 v1 不开放（WebCodecs 播放管线后续批次）。
- **net**：Web 无 UDP（显式报错）；TCP = WebSocket 同协议同分帧
  （**一条 WS 消息 = 一帧裸载荷**——4 字节大端长度前缀是 raw TCP
  形态专用，WS 消息内不含前缀）。
